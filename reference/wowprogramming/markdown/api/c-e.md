## ceil

Returns the smallest integer larger than or equal to a number. Alias for the standard library function `math.ceil`.

**Signature:** `ceiling = ceil(x)`

**Arguments:**
- `x` - A number (`number`)

**Returns:**
- `ceiling` - Smallest integer larger than or equal to `x` (`number`)
